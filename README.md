## 一、功能一览

**核心功能（作业要求）**

1. **发布信息**：发布「寻物 / 招领」两类信息，字段含物品名称、分类、地点、日期、称呼、联系方式、备注；
2. **集中浏览**：首页信息墙按时间倒序展示全部信息，支持 类型（全部/寻物/招领）× 分类 × 状态 三重筛选；
3. **关键词搜索**：按物品名称、地点、备注、发布人搜索，多关键词空格分隔（AND 语义），英文不区分大小写；
4. **查看详情**：完整信息 + 发布者联系方式，支持**一键复制联系方式**（手机号可直达“拨打电话”）；
5. **更新状态**：物品找回 / 归还后，**发布者**可把信息标记为「已找到」（寻物）或「已归还」（招领），误标记可一键恢复，支持删除（二次确认）。完成后所有用户都能在首页卡片、搜索结果、详情页看到灰显徽章与提示。

**附加特点**

- 一键复制联系方式（自动拼接物品与联系人信息，复制即可去联系）；
- 按物品分类筛选（电子数码 / 证件卡类 / 生活用品 / 衣物配饰 / 钥匙工具 / 其他）；
- 发布表单就地校验：逐字段红框 + 中文原因提示，日期不允许晚于今天；
- 搜索空结果兜底：引导“换关键词 / 去发布”，不留死胡同；
- 首次打开自动灌入 8 条演示数据（可在「我的发布」页一键重置或清空）；
- 相对时间显示（刚刚 / N 分钟前 / 昨天）与信息编号，便于对照沟通；
- 纯本地运行：数据保存在浏览器 localStorage，不依赖任何服务器。

## 三、如何运行

### 环境要求

- 谷歌浏览器（Chrome）即可，无需安装任何东西、无需联网、无需构建工具。
- 开发与测试统一使用 Chrome（按作业要求）。

### 运行步骤

1. 下载 / 克隆本仓库的全部文件（保持目录结构不变）；
2. 双击打开 `index.html`；
3. 完成。首次打开会自动载入 8 条演示数据，可直接体验浏览、搜索、详情、发布、状态标记全流程。

> 备注：若浏览器策略限制了 `file://` 下的本地存储（页面顶部会出现一条提示），数据将仅本次会话有效；此时可用任意静态服务器运行，例如在项目根目录执行 `python -m http.server 8080` 后访问 `http://localhost:8080/index.html`。

### 单元测试

- **方式一（推荐，零环境）**：双击打开 `test/test.html`，页面即显示 Mocha 测试报告（44 个用例，全部应显示绿色通过）；
- **方式二（开发者）**：在 `第四次作业/` 目录下执行 `npx mocha@10.8.2 test/core.test.js test/validate.test.js test/search.test.js test/util.test.js`。

## 四、使用说明（核心流程走查）

以“捡到耳机的同学”和“丢了耳机的同学”为例，完整走一遍作业要求的主流程：

1. **发布招领**：底部导航点【发布】→ 切到“我捡到了东西（招领）”→ 填写信息 → 【立即发布】→ 弹出成功提示；
2. **浏览与搜索**：首页信息墙立刻能看到新发布的信息；顶部筛选可按“寻物/招领”“分类”“状态”组合过滤；搜索页输入“耳机”可命中（试试输入两个词如“蓝色 耳机”，或多搜几个热门词）；
3. **查看详情并联系**：点击卡片进入详情页，点【一键复制联系方式】即可去 QQ / 微信联系发布者；
4. **更新状态（闭环）**：物品归还后，发布者打开这条信息的详情页（或进入【我的】页），点击**标记为已归还** → 该信息立刻变为“已完成”：首页与搜索结果里灰显并带「已归还」徽章，详情页显示绿色横幅，避免其他同学继续联系；
5. **异常流试试看**：发布页直接点【立即发布】（空表单）→ 5 个字段就地报错；搜索一个不存在的词 → 空状态引导；误标记 → 详情页可“恢复为进行中”；测试数据乱了 → 【我的】页底部“载入演示数据 / 清空全部数据”。

## 五、设计约定（写给测试同学）

- **发布者身份**：本应用不设账号（作业明确不做实名认证），“我的发布”以**发布时所在的浏览器**为准——谁在本机发布，本机就能管理（标记状态 / 删除）。真实产品应接入账号体系，此处为作业范围的简化，README 特此说明；
- **数据迁移**：直接复制文件不会带走数据，数据在浏览器里；换浏览器或清除浏览器数据后，历史发布将无法管理；
- **编码**：全部文件为 UTF-8，若出现乱码请确认用 Chrome 打开（作业统一浏览器）。
